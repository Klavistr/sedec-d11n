# 文章スタイルガイド

## 基本方針

- 読者が次に何をすればよいか判断できる、簡潔で具体的な文章にする。
- 読者を「スタッフ」「スピーカー」「リスナー」のいずれかとして明確に想定する。
- 原則として敬体（です・ます調）を使う。
- 未確定事項は「予定」「検討中」「仮」などと明記し、確定事項と混ぜない。
- 日付、場所、金額、締切、連絡先は一次資料と照合する。

## 表記

- イベント名は「性DEC」と表記する。
- 半角英数字を使い、英数字の前後には必要に応じて半角スペースを入れる。
- 日付は、年を含む場合は `2026年12月19日` の形式を基本とする。
- 時刻は `10:30` のように 24 時間表記にする。
- UI ラベルやコマンドは、意味の違いが生じないよう原文の表記を保つ。

## 構造

- 概念説明では、結論または目的を先に書く。
- 手順では、前提条件を示してから番号付きの操作を書く。
- 注意事項は、どの操作や判断に関係するかが分かる位置に置く。
- 見出しだけで内容を推測できるようにし、「概要」「その他」の多用を避ける。

## アクセシビリティー

- 画像には内容を説明する代替テキストを付ける。
- 色だけで状態や重要度を区別しない。
- リンクテキストはリンク先の内容が分かる語句にし、「こちら」だけにしない。
- 略語は初出時に正式名称または意味を添える。
